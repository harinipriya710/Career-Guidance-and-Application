# Career Guidance and Application

A web-based career guidance platform designed to help students explore career paths, courses, competitive exams, and learning resources.

## Features
- Student Login and Registration
- Career Guidance Information
- Course Recommendations
- Competitive Exam Guidance
- Interactive Chatbot
- Responsive User Interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Tailwind CSS
